# Доклад по книге В.С. Соловьёва «Смысл любви»

Репозиторий содержит исходный текст книги и подготовленный по нему доклад.

## Что где лежит

| Файл | Что это |
|---|---|
| `Соловьев Владимир_смысл любви.doc` | исходный файл книги (внутри — RTF, кодировка cp1251) |
| `ДОКЛАД.md` | текст доклада: введение, пять разделов по статьям, возражения, заключение |
| `ДОКЛАД.docx` | тот же доклад в Word |
| `ЦИТАТЫ.md` | 13 проверенных цитат с привязкой к статьям и назначением в докладе |
| `СЛАЙДЫ.md` | тезисы для 10 слайдов |
| `source/01-statya.md` … `05-statya.md` | текст книги, разбитый по пяти статьям (для цитирования и проверки) |

## Как готовился доклад

1. Из `.doc` извлечён текст (файл внутри — RTF, поэтому текст разобран по `\'hh`-последовательностям cp1251), разбит на пять статей.
2. Каждая статья разобрана отдельным агентом: тезис, аргументы, цитаты, возражения, место в замысле книги.
3. Цитаты сверены с текстом скриптом — все 13 совпадают дословно (исправлены только артефакты распознавания внутри слов).
4. Доклад собран из разборов: введение, пять разделов по статьям, свод возражений, заключение.

## Структура доклада

1. Любовь — не средство размножения (статья первая)
2. Смысл любви: спасение личности через жертву эгоизма (статья вторая)
3. Любовь как задача, а не состояние (статья третья)
4. Мистика целостности: плоть, смерть и вечная Женственность (статья четвёртая)
5. От пары к всеединству (статья пятая)
6. Возражения к концепции в целом
7. Заключение

## Источник

В.С. Соловьёв. «Смысл любви», статьи первая–пятая (1892–1894). Текст находится в общественном достоянии.
